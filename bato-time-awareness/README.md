## 1. 構成（3点のみ・外部サービス追加なし）

| ファイル | 役割 |
|---|---|
| `now_jst.py` | 実行環境の時計(UTC)をJSTへ変換し、日付・曜日・時刻・時間帯・運用ルールを出力。標準ライブラリのみ |
| `settings.example.json` | SessionStart と UserPromptSubmit の2つのHook設定例 |
| `README.md` | 本書（導入手順、AGENTS.md追記案、テスト結果） |

仕組み: Hook(時刻取得) → 会話に自動注入 → バトーがGoogleカレンダー(既存コネクタ)で本日予定を確認 → 時間軸で判断。
Hookはカレンダーを直接呼べないため、「予定は必ずカレンダーで確認する」ルールを注入文に含めています。

## 4. AGENTS.md への追記案（未適用・承認待ち）

> ## 時間認識ルール
> - 日付・曜日・時刻は Hook が注入する日本時間を使う。推測しない
> - 作業開始時にGoogleカレンダーで本日の予定を確認し、締切・残務を時間軸で優先順位づけする
> - 朝・昼・夕方で優先順位を見直す（朝=今日の最優先、昼=進捗と詰まり、夕方=残務と明日への持ち越し）
> - 日付が変わっても、未完了の業務を完了扱いにしない。CURRENT に残す
> - 「バトーの作業完了」と「府川さんの業務終了」は別。時刻だけで終了判断をしない。終了を宣言しない
> - 府川さんが終了を伝えたら、未完了業務と翌日の引き継ぎを整理して CURRENT に反映する
