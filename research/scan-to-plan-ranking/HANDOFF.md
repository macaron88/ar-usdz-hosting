# ローカル環境での続行手順

このリポジトリのリモートセッションは、組織のエグレスポリシーにより外部サイトへ接続できず、
調査が**発見フェーズ完了・立証フェーズ未了**の状態で止まっている。
ローカルの Claude Code で以下をそのまま実行すれば続行できる。

## 1. 取得

```
git clone https://github.com/macaron88/ar-usdz-hosting.git
cd ar-usdz-hosting
git checkout claude/reform-survey-app-ranking-8mf5co
```

## 2. Claude Code に貼るプロンプト

```
research/scan-to-plan-ranking/ の調査を続行して。

README.md に設計、rubric.md に採点規則、schema.json に共通項目、
agent-prompts.md に各フェーズの指示文、field-test.md に実測プロトコルがある。
candidates.json が母集団117件、evidence/ に立証途中のデータ、
studies.json に精度検証文献の書誌がある。

前提条件（確定済み）:
- 用途は見積用。面積と主要寸法が合っていればよい
- 出力形式は足切りにしない。DXFでもBIMでも可。ただし種類は網羅的に一覧化する
- 現場はひとりスキャン、LiDAR前提

これまでの制約: リモート環境で外部サイトへ一切接続できず、
evidence/ の内容はすべて検索スニペット由来で一次情報ではない。
ローカルなら取得できるはずなので、まず接続を確認してから立証フェーズをやり直して。

優先順位:
1. 各社の公式Pricingページを実際に取得して価格を確定する
   （Metaroom・ArcSite・magicplan・Polycam は現在4系統の矛盾した価格が併存し使用不能）
2. 壁面積から開口部が自動控除されるかを各社ヘルプで確認する
   （見積用途で最も効く。現在 magicplan 以外は全製品で未確認）
3. 出力形式を 2D CAD / BIM / 3D / 点群 / 数量 / 閲覧 / 見積特化 に分類して全製品分を埋める
4. サンプルDXF・サンプル図面を実ファイルでダウンロードし、CADで開いて所見を記録する
5. 間取りスキャナー（キャドネット）の料金を確認する。公開情報に一切ない
6. 日本の作図代行がiPhone LiDARスキャンや点群を受け付けるかを確認する
   （現状すべて既存図面のトレース前提。ここが空白）

取得した値には必ず claim_type / source_url / quote / fetched_at を付けること。
取得できなかった項目は推測で埋めず unknown を残すこと。
ベンダーの記述は事実ではなく主張として記録すること。

終わったら report.html を再生成して、順位ではなく確定した事実として提示して。
```

## 3. 完了後

順位は机上では確定しない。`field-test.md` の同一物件テストを現場担当者本人が実施し、
撮影時間＋修正時間の実測値で並べたところで初めてランキングになる。
