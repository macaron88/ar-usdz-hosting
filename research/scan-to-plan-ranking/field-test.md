# 同一物件テスト（実測プロトコル）

順位はここで決まる。並列化しない。ショートリスト5〜6本のみ実施。

## 前提

用途は**見積用**。測るのは点群の精度ではなく、
**出てきた図面から拾った面積・寸法が見積を壊さないか**。

## 準備

1. 対象を1つ決める。典型的な現調1件（LDK + 水回り、または実際の受注物件1戸）
2. **正解値を先に確定する**
   - 各部屋の内法寸法（巻尺またはレーザー距離計、2回測って一致を確認）
   - 各部屋の床面積
   - 開口部（ドア・窓）の幅・高さと位置
   - 天井高
3. 家具はそのまま。動かさない（ひとり運用の実態に合わせる）

## 実施

各製品について、以下を1回のセッションで行う。

| 計測項目 | 測り方 |
|---|---|
| 撮影時間 | アプリを開いてからスキャン完了操作までの実時間 |
| 待ち時間 | 完了操作から図面/データが手元に来るまで（**主KPIには加算しない。別掲**） |
| 修正時間 | 見積に使える状態にするまでの実作業時間 |
| 修正の担当 | 現場担当者本人でできたか / CAD が分かる人が必要だったか |
| 失敗回数 | スキャンをやり直した回数。中断からの復帰可否 |

### 条件

- **スキャンは現場担当者本人が行う**。調査者が上手にスキャンできても意味がない
- 補助者なし、三脚なし、片手操作で
- 製品の実施順はシャッフルする（部屋に慣れることによる順序効果を避ける）
- 同日・同照明で全製品を回す

### 追加で必ず行う2つ

- **再現性テスト**: 1部屋を2回スキャンし、出てきた面積・寸法が一致するか
- **オフラインテスト**: 機内モードで1回。スキャンが完了できるか、
  完了できてもアップロード待ちで止まらないか

## 記録

`field-test-results.csv`

```
product, scan_min, wait_min, fix_min, kpi_min, fixer, retries,
area_err_pct, dim_err_mm, repeat_area_err_pct, offline_ok, notes
```

- `kpi_min = scan_min + fix_min`（wait_min は含めない）
- `area_err_pct` = (図面から拾った床面積 - 正解値) / 正解値
- `dim_err_mm` = 主要寸法の誤差の最大値

## 判定

- 足切り: `area_err_pct` ±3% 以内 かつ `dim_err_mm` ±50mm 以内 かつ 再現性が同範囲
- 順位: 足切り通過分を `kpi_min` の昇順に並べる
